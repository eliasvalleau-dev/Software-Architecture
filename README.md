# Software-Architecture
Repository to handle Structurizr DSL diagrams

## Structurizr entry point

Use `C4Diagram.txt` as the single Structurizr DSL entry point.

During the staged consolidation of the former cloud/deployment and code
workspaces, their original source is retained as commented migration sections
at the end of `C4Diagram.txt`. Those sections are intentionally ignored by
Structurizr and will be migrated into live views in subsequent commits.
